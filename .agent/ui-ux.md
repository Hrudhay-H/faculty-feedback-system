# UI/UX Direction

Build a modern academic SaaS-style dashboard.

Avoid:

- outdated college portal aesthetics
- excessive gradients
- unnecessary animations
- excessive rounded cards
- giant hero sections
- random colors

Use:

- clean typography
- consistent spacing
- clear hierarchy
- subtle shadows
- restrained animations
- responsive layouts
- professional dashboard components

## Student Experience

Prioritize:

- clarity
- simple navigation
- obvious feedback status
- easy rating interaction
- minimal friction

## Faculty Experience

Prioritize:

- analytics
- trends
- question-level performance
- actionable insights

## Admin Experience

Prioritize:

- data density
- tables
- filters
- management workflows
- system statistics

## Feedback Form

Use a clear rating interface.

Rating scale:

1 = Very Poor
2 = Poor
3 = Average
4 = Good
5 = Excellent

Display progress while filling the form.

Prevent accidental submission.

Show a confirmation before final submission.
